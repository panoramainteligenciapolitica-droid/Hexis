# Hexis

Ficha de treino que se ajusta toda semana, com cardio, corpo e dieta.

- Site: https://panoramainteligenciapolitica-droid.github.io/Hexis/
- Login e dados: Supabase (projeto `hexis`). Cada pessoa só lê e grava as próprias linhas da tabela `hexis_docs` (RLS).
- Um único arquivo (`index.html`), sem etapa de build. Pode ser instalado no celular pelo navegador ("Adicionar à tela inicial").
